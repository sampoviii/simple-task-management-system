A lightweight, web-based task management application built with PHP and MySQL to help users organize, track, and manage their daily tasks efficiently.

### Features
* Task Creation and Management: Add new tasks with details, edit existing entries, and delete completed or unwanted items.
* Status Tracking: Monitor and update task progress (pending, in-progress, or completed).
* Database-Backed Storage: Persists all task records reliably using a relational MySQL database.
* Clean Web Interface: Simple and responsive layout accessible directly through any web browser.

### Tech Stack
* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL / phpMyAdmin
* Hosting: InfinityFree
